# TAC-MAP // Xeneon Edge Interface

Tactical briefing map interface styled after **Ace Combat**, optimized for touchscreens and the Corsair Xeneon Edge screen.

## ✨ Features
* **Ace Combat Aesthetic:** Military tactical UI with grid lines and clean typography.
* **Live Info:** Displays current local time and weather for your configured location.
* **Touch Optimized:** Built for tactile commands and secondary displays.
* **Unit Deployment:** Tap buttons to add units to your chosen side of the map.

## ⚙️ Configuration
To change the weather location, open the code (`script.js` or `index.html`) and update your city or coordinates in the config section.

## 🚀 Getting Started
1. Open ICUE, select iframe widget and add the code.
2. Enjoy your tactical setup!

   Or
   
1. Open `index.html` in your browser or display software.
2. Enjoy your tactical setup!
